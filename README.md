# مدیریت ساختمان (BuildingManager)

**نرم‌افزار رایگان و آفلاین مدیریت ساختمان؛ با ۱۰۰٪ کد منبع تولیدشده توسط هوش مصنوعی (AI).**

BuildingManager یک نرم‌افزار دسکتاپ برای مدیریت امور مالی و اجرایی ساختمان‌های مسکونی است.

نکته ویژه این پروژه، روش توسعه آن است: **تمام کد منبع برنامه با استفاده از هوش مصنوعی تولید شده است.** ایده‌پردازی، تعیین نیازمندی‌ها، هدایت فرایند توسعه، بررسی و آزمایش خروجی‌ها توسط توسعه‌دهنده انجام شده است.

هدف پروژه ارائه ابزاری رایگان، کاربردی و آفلاین برای مدیریت ساده‌تر ساختمان‌هاست.

## امکانات

- مدیریت واحدهای ساختمان
- ثبت و مدیریت اطلاعات مالکان و مستأجران
- مدیریت شارژ ساختمان و پرداختی‌ها
- ثبت هزینه‌ها و درآمدهای متفرقه
- محاسبه و پیگیری بدهکاری و بستانکاری
- مشاهده گزارش‌های مالی ماهانه
- تهیه گزارش‌های PDF
- خروجی گرفتن به فرمت Excel
- تهیه گزارش مالی چندماهه
- پشتیبانی از تقویم شمسی
- رابط کاربری چندزبانه
- تهیه نسخه پشتیبان از اطلاعات
- ذخیره‌سازی محلی اطلاعات با SQLite
- امکان استفاده بدون نیاز به اینترنت

## دانلود و نصب

برای دریافت آخرین نسخه برنامه به صفحه انتشارها مراجعه کنید:

[دانلود آخرین نسخه BuildingManager](../../releases/latest)

فایل نصب ویندوز را از قسمت Assets دانلود و اجرا کنید.

## فناوری‌ها و نحوه توسعه

- **زبان برنامه‌نویسی:** Python
- **رابط گرافیکی:** Tkinter
- **پایگاه داده:** SQLite
- **تولید کد منبع:** ۱۰۰٪ با هوش مصنوعی
- **هدایت پروژه:** توسط توسعه‌دهنده
- **آزمایش و بررسی:** توسط توسعه‌دهنده

- ## راهنمای نصب و سیستم‌عامل

### سیستم‌عامل پشتیبانی‌شده
- Windows 10
- Windows 11

### پیش‌نیازها
- سیستم‌عامل ویندوز ۶۴ بیتی
- نیازی به نصب جداگانه Python نیست.
- نیازی به نصب SQLite نیست.
- برای استفاده معمول، اتصال به اینترنت لازم نیست.

### مراحل نصب
1. به صفحه [آخرین نسخه برنامه](../../releases/latest) بروید.
2. فایل `BuildingManager_Setup.exe` را از قسمت Assets دانلود کنید.
3. فایل نصب را اجرا کنید.
4. مراحل نصب را دنبال کنید.
5. پس از پایان نصب، برنامه را از میان‌بر دسکتاپ یا منوی Start اجرا کنید.

### حذف نصب
برای حذف برنامه، از بخش **Settings → Apps** ویندوز یا گزینه **Uninstall** در منوی Start استفاده کنید.

**نکته:** پیش از حذف برنامه یا جابه‌جایی اطلاعات، از پایگاه داده خود نسخه پشتیبان تهیه کنید. حذف برنامه ممکن است بسته به محل ذخیره اطلاعات، روی فایل‌های داده تأثیر بگذارد.

تمام کدهای برنامه BuildingManager با استفاده از هوش مصنوعی تولید شده‌اند. این پروژه نمونه‌ای از توسعه یک نرم‌افزار واقعی با کمک ابزارهای هوش مصنوعی است.

## حریم خصوصی

اطلاعات ساختمان روی رایانه کاربر ذخیره می‌شوند. برنامه برای استفاده معمول به حساب کاربری آنلاین یا فضای ابری نیاز ندارد.

توصیه می‌شود به‌صورت منظم از اطلاعات خود نسخه پشتیبان تهیه کنید.

## گزارش مشکلات و پیشنهادها

اگر با مشکلی مواجه شدید یا پیشنهادی برای بهتر شدن برنامه دارید، می‌توانید از بخش Issues در همین مخزن استفاده کنید.

## حمایت از توسعه‌دهنده

استفاده از برنامه رایگان است. در صورت تمایل می‌توانید از توسعه و بهبود برنامه حمایت مالی کنید.

## وضعیت پروژه

BuildingManager یک پروژه نرم‌افزاری رایگان و متن‌باز است که با هدف ساده‌تر کردن مدیریت ساختمان توسعه داده شده است.

**ویژگی خاص پروژه:** صددرصد کد منبع برنامه توسط هوش مصنوعی تولید شده است؛ فرایند توسعه، تعیین نیازمندی‌ها، هدایت تغییرات و آزمایش نرم‌افزار توسط توسعه‌دهنده انجام شده است.
