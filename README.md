# مدیریت ساختمان | BuildingManager

**نرم‌افزار رایگان و آفلاین مدیریت ساختمان؛ تمام کد منبع این پروژه با هوش مصنوعی تولید شده است.**

ایده‌پردازی، تعیین نیازمندی‌ها، هدایت توسعه، بررسی و آزمایش خروجی‌ها توسط توسعه‌دهنده انجام شده است.

## نسخه 18.7
این نسخه ساختار کد را به ماژول‌های مستقل تقسیم می‌کند و فرایند ساخت نصب‌کننده ویندوز را استاندارد می‌سازد.

## امکانات
- مدیریت واحدها، مالکان و مستأجران
- مدیریت شارژ، پرداخت‌ها، هزینه‌ها و درآمدهای متفرقه
- محاسبه بدهکاری و بستانکاری
- گزارش‌های ماهانه، چندماهه و سالانه
- خروجی PDF و Excel
- تقویم شمسی و رابط کاربری چندزبانه
- پشتیبان‌گیری و بازیابی اطلاعات
- ذخیره‌سازی محلی با SQLite و عملکرد آفلاین

## ساختار پروژه
```text
.
├── building_manager/
│   ├── runtime.py       # تنظیمات، لاگ و مدیریت خطا
│   ├── helpers.py       # توابع عمومی، عدد و تاریخ
│   ├── i18n.py          # ترجمه‌ها و زبان‌ها
│   ├── database.py      # پایگاه داده و منطق ذخیره‌سازی
│   ├── widgets.py       # اجزای رابط کاربری
│   ├── reports.py       # گزارش‌ها و خروجی‌ها
│   ├── app.py           # پنجره و صفحات اصلی برنامه
│   └── entrypoint.py    # راه‌اندازی و آزمون‌های داخلی
├── main.py
├── installer.iss
├── requirements-build.txt
└── .github/workflows/build.yml
```

## دانلود و نصب ویندوز
1. به [صفحه آخرین انتشارها](../../releases/latest) بروید.
2. فایل `BuildingManager_Setup.exe` را از قسمت Assets دریافت کنید.
3. نصب‌کننده را اجرا و مراحل را تکمیل کنید.
4. برنامه را از منوی Start یا میان‌بر دسکتاپ اجرا کنید.

**سیستم‌عامل هدف:** Windows 10 و Windows 11، نسخه ۶۴ بیتی. برای اجرای نسخه نصب‌شده نیازی به نصب جداگانه Python یا SQLite نیست.

## اطلاعات و حریم خصوصی
پایگاه داده و پشتیبان‌ها در مسیر زیر ذخیره می‌شوند و با نصب یا حذف برنامه پاک نمی‌شوند:

`%USERPROFILE%\\BuildingManagerData`

اطلاعات به‌صورت محلی روی رایانه کاربر نگهداری می‌شوند؛ برنامه برای استفاده عادی به اینترنت یا حساب آنلاین نیاز ندارد. تهیه پشتیبان منظم توصیه می‌شود.

## فناوری‌ها
- Python 3.13 برای فرایند ساخت
- Tkinter برای رابط گرافیکی
- SQLite برای ذخیره‌سازی
- PyInstaller برای بسته‌بندی برنامه
- Inno Setup برای ساخت نصب‌کننده ویندوز

## توسعه و ساخت
اجرای سورس:
```bash
python main.py
```

نصب ابزارهای ساخت:
```bash
python -m pip install -r requirements-build.txt
```
